EWEB – Portfolio

Berner Fachhochschule

Willkommen in meinem Portfolio zum Modul EWEB.

Dieses Portfolio dokumentiert meine Arbeiten, Projekte und Lernerfahrungen während des Moduls. Dabei steht die praktische Anwendung von Konzepten der modernen Webentwicklung im Mittelpunkt.

Inhalt

Im Portfolio werden unter anderem folgende Themen und Arbeiten behandelt:

* Entwicklung und Strukturierung von Webseiten
* HTML und CSS
* JavaScript und interaktive Webanwendungen
* Responsive Webdesign
* Benutzerfreundlichkeit und Web Usability
* Entwicklung und Umsetzung eigener Webprojekte
* Reflexion und Dokumentation der erlernten Inhalte

Ziel des Portfolios

Das Portfolio dient dazu, meine im Modul erworbenen Kenntnisse und Fähigkeiten sichtbar zu machen und meinen persönlichen Lernfortschritt zu dokumentieren.

Neben den technischen Ergebnissen werden auch die Vorgehensweise, Herausforderungen und gewonnenen Erkenntnisse festgehalten.

Über mich

Ich studiere Wirtschaftsinformatik an der Berner Fachhochschule. Im Studium beschäftige ich mich mit der Verbindung von Informatik, Digitalisierung und betriebswirtschaftlichen Fragestellungen.

Das Modul EWEB bietet dabei die Möglichkeit, theoretische Inhalte direkt in praktischen Webprojekten anzuwenden und eigene Lösungen zu entwickeln.

Technologien

Je nach Projekt kommen unter anderem folgende Technologien zum Einsatz:

* HTML5
* CSS3
* JavaScript
* Git / GitHub
* Weitere Webtechnologien gemäss Modulinhalt

Aufbau

Die einzelnen Bereiche des Portfolios enthalten jeweils eine kurze Beschreibung der Aufgabe, die entwickelte Lösung sowie eine Reflexion über den Entwicklungsprozess und die wichtigsten Erkenntnisse.
